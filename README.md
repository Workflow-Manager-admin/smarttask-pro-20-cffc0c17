# SmartTask Pro

SmartTask Pro is an enhanced ToDo application designed to help users efficiently manage their daily tasks with advanced features such as reminders, categorization, and progress tracking.

## Features

- **Task Management:** Create, edit, delete, and mark tasks as complete or incomplete.
- **Reminders:** Set reminders to receive notifications at specified times.
- **Task Categories:** Organize your tasks with customizable categories.
- **Progress Tracking:** Monitor completion progress and view statistics.
- **Search & Filter:** Quickly find and filter tasks by keywords, categories, or status.

## Tech Stack

- **Frontend:** React JS (ES6+)
- **Language:** JavaScript
- **UI Theme:** Light, clean, and modern

## Getting Started

1. **Install dependencies:**

   ```bash
   cd smarttask_pro
   npm install
   ```

2. **Run the app in development mode:**

   ```bash
   npm start
   ```

   Open [http://localhost:3000](http://localhost:3000) to view in your browser.

3. **Run tests:**

   ```bash
   npm run test
   ```

4. **Build for production:**

   ```bash
   npm run build
   ```

## Project Structure

- `/smarttask_pro/src/` - React source code
- `/smarttask_pro/public/` - Static public assets

## Customization

Update colors, add new features, and adjust layout as needed in the source files within the `smarttask_pro` directory.
